Un flujo, de principio a fin

  1. Preparar el artículoTexto, resumen, autor, idioma, etiquetas y SEO.
  2. Montarlo en StudioCompletar los campos, pegar el Markdown y subir las imágenes.
  3. Revisar el borradorComprobar la vista visual, los enlaces y la portada.
  4. Publicar cuando correspondaPublicar o actualizar según el encargo y abrir el artículo para verificarlo.

Todo desde la consola. Los nuevos posts no necesitan cambios en el repositorio ni despliegues.
